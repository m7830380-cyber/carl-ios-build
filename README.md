# carl-ios-build

Build runner only. This public repo holds a GitHub Actions workflow and generic CI scripts that build an
iOS IPA from a **private** Unity project (checked out with a token secret). It contains no game files,
no game code and nothing derived from them; build logs and outputs are stored in the private repo only.

Credits for the game: Project C.A.R.L. by **CarlRagdoll** (Untitled Ragdoll Simulator),
music @alex_beres_, weapon models & store art @MaxxwellWMax.
